Red Flag

Einmalig einrichten

Red Flag holt die Google-Bewertungen über Apify. Das Gratis-Konto enthält jeden Monat 5 $ Guthaben, das reicht für über 10 000 Bewertungen.

  1. Gratis bei Apify registrieren (z. B. mit Google).
  2. In Apify: Settings → API & Integrations, den „Personal API token“ kopieren.
  3. Hier einfügen und speichern. Er bleibt nur auf diesem Handy.

Restaurant

In Google Maps beim Restaurant auf „Teilen“ → „Link kopieren“ tippen.
